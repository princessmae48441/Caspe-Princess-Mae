## 1. Brief Overview

**Microsoft Azure** is a cloud computing platform developed by Microsoft. It provides a wide range of cloud services for **computing, storage, databases, networking, security, analytics, artificial intelligence, and application development**.

Azure allows organizations to build, deploy, and manage applications and IT resources using Microsoft's cloud infrastructure. It supports both cloud-based and hybrid environments for different business requirements.

---

## 2. Global Infrastructure

Azure operates a worldwide cloud infrastructure made up of **geographic regions, datacenters, and Availability Zones**.

An **Azure Region** is a geographic area that contains one or more datacenters. Azure regions allow organizations to deploy applications and services closer to their users to help improve performance and meet data residency requirements.

Azure also provides **Availability Zones** in supported regions. Availability Zones are physically separate locations within an Azure region and are designed to help protect applications from localized datacenter failures.

Azure's global infrastructure supports requirements such as:

- High availability
- Low latency
- Data residency
- Security
- Scalability
- Disaster recovery

This global infrastructure allows organizations to deploy their applications in locations that are appropriate for their business and technical requirements.

---

## 3. Cloud Management Console

The **Azure Portal** is Microsoft's web-based management console for Azure.

It provides a graphical interface for creating, managing, monitoring, and configuring Azure resources and services.

Through the Azure Portal, users can:

- Create cloud resources
- Manage virtual machines
- Manage storage
- Configure networking
- Manage databases
- Monitor applications
- Manage subscriptions
- Monitor costs
- Manage users and permissions
- Access Azure services

The Azure Portal provides a centralized way to manage Azure resources through a web browser.

---

## 4. Four Core Azure Services

### 1. Azure Virtual Machines

**Azure Virtual Machines** provides virtual computers that can run Windows or Linux workloads in the cloud.

Organizations can use virtual machines to run applications, services, and other workloads without purchasing and maintaining physical servers.

**Main Purpose:** Virtual Computing

---

### 2. Azure Blob Storage

**Azure Blob Storage** is an object storage service designed for storing large amounts of unstructured data.

Examples include:

- Documents
- Images
- Videos
- Backups
- Application data

**Main Purpose:** Cloud Storage

---

### 3. Azure SQL Database

**Azure SQL Database** is a fully managed relational database service based on Microsoft SQL technologies.

It allows organizations to store, manage, and access structured data without having to manage the underlying database infrastructure.

**Main Purpose:** Managed Databases

---

### 4. Azure Functions

**Azure Functions** is a serverless computing service that allows developers to run code in response to events without directly managing the underlying servers.

It can be used for event-driven applications, automated tasks, and backend processing.

**Main Purpose:** Serverless Computing

---

## 5. Three Advantages of Azure

### 1. Global Infrastructure

Azure provides a worldwide network of cloud regions and datacenters.

This allows organizations to deploy applications in locations that are suitable for their users and business requirements.

### 2. Microsoft Integration

Azure integrates with Microsoft technologies and enterprise environments.

This makes Azure useful for organizations that already use Microsoft products and services such as Windows Server, Microsoft SQL Server, Microsoft 365, and other Microsoft technologies.

### 3. Scalability

Azure resources can be increased or decreased according to the requirements of applications and workloads.

This allows organizations to adjust their cloud resources as demand changes.
