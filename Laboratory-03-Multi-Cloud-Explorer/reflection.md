#  Reflection

This mission helped me understand cloud computing better because I was able to compare AWS, Azure, and GCP and see how they can be used in real situations. The cloud platform that impressed me the most was **AWS**. I chose AWS because it has many services that can be used for different purposes, especially for computing, storage, databases, and networking. I also found it easier to understand how a Linux server can be moved to the cloud using services like Amazon EC2.

AWS, Azure, and GCP have many similarities. All three provide cloud services for computing, storage, networking, databases, security, and monitoring. They also allow users to scale resources depending on how much they need. Another similarity is that all of them can be used to host applications and Linux servers. Although they have different service names and features, they provide similar types of solutions.

Business requirements are important when choosing a cloud platform. A company should consider its budget, security needs, performance, storage requirements, and the number of users it needs to support. The company should also consider the skills of its IT staff. Choosing a cloud provider should depend on what the business actually needs instead of simply choosing the most popular platform.

Acting as a **Cloud Solutions Consultant** taught me that choosing a cloud service requires research and comparison. I learned that I should first understand the problem and requirements before recommending a service. I also learned how important it is to explain technical information in a simple way.

After completing this mission, my **GitHub Cloud Computing Portfolio** became more organized and complete. I was able to add cloud research, provider comparisons, infrastructure information, Linux server investigation, screenshots, and my reflection. This mission also gave me more confidence in explaining basic cloud computing concepts and making simple cloud recommendations.
