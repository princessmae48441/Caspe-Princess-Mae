# Google Cloud Platform (GCP) Research

> **Cloud Platform:** Google Cloud Platform (GCP)  
> **Provider:** Google  
> **Category:** Public Cloud Computing Platform

---

## 1. Brief Overview

**Google Cloud Platform (GCP)**, commonly called **Google Cloud**, is a cloud computing platform provided by Google. It offers a wide range of cloud services for **computing, storage, databases, networking, data analytics, artificial intelligence, machine learning, security, and application development**.

Google Cloud allows organizations to build, deploy, and manage applications using Google's global cloud infrastructure.

It provides services that support businesses, developers, and enterprises in managing applications, data, and IT workloads in the cloud.

---

## 2. Global Infrastructure

Google Cloud organizes its infrastructure into **Regions** and **Zones**.

A **Google Cloud Region** is an independent geographic area where Google Cloud provides cloud infrastructure. Each region contains multiple **Zones**, which are separate locations within a region.

Organizations can distribute resources across multiple zones or regions to improve application availability and reliability.

Google Cloud also operates a global network that connects its cloud infrastructure around the world.

Its global infrastructure supports requirements such as:

- High availability
- Low latency
- Scalability
- Reliability
- Global connectivity
- Disaster recovery

This infrastructure allows organizations to deploy applications and services in locations that are appropriate for their users and business requirements.

---

## 3. Cloud Management Console

The **Google Cloud Console** is a web-based interface used to manage Google Cloud resources and services.

Through the Google Cloud Console, users can:

- Create and manage cloud resources
- Manage virtual machines
- Configure storage
- Manage databases
- Configure networking
- Monitor applications
- Manage projects
- Manage users and permissions
- Monitor cloud resources
- Manage billing
- Access Google Cloud services

The Google Cloud Console provides a centralized way to manage Google Cloud resources through a web browser.

---

## 4. Four Core Google Cloud Services

### 1. Compute Engine

**Google Compute Engine** provides virtual machines that run on Google's infrastructure.

Organizations can use Compute Engine to run applications, websites, and other workloads using virtual machines in the cloud.

**Main Purpose:** Virtual Computing

---

### 2. Cloud Storage

**Google Cloud Storage** is an object storage service used to store and retrieve different types of data.

Examples include:

- Documents
- Images
- Videos
- Backups
- Application data

**Main Purpose:** Cloud Storage

---

### 3. Cloud SQL

**Cloud SQL** is a fully managed relational database service.

It supports database systems such as:

- MySQL
- PostgreSQL
- SQL Server

Cloud SQL helps organizations manage relational databases without having to maintain the underlying database infrastructure themselves.

**Main Purpose:** Managed Databases

---

### 4. Cloud Run

**Cloud Run** is a fully managed platform for running containerized applications.

It allows developers to deploy applications without directly managing the underlying servers and infrastructure.

Cloud Run is useful for web applications, APIs, and other container-based workloads.

**Main Purpose:** Serverless Application Hosting

---

## 5. Three Advantages of Google Cloud

### 1. Global Network

Google Cloud uses Google's global infrastructure and network to connect cloud resources and locations around the world.

This provides organizations with global connectivity and allows applications to be deployed closer to their users.

### 2. Data and AI Capabilities

Google Cloud provides services for **data analytics, artificial intelligence, and machine learning**.

These capabilities allow organizations to process large amounts of data and develop intelligent applications.

### 3. Scalability

Google Cloud resources can be scaled according to application requirements and changes in workload.

This allows organizations to adjust their resources as demand increases or decreases.
