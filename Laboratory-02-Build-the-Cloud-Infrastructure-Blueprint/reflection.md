# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, the **compute resource** is one of the most important parts of cloud infrastructure because it is responsible for processing tasks and running applications. During the KillerCoda activity, I was able to see that the server had one CPU core and limited memory. This helped me understand that the performance of a cloud system depends on the computing resources available to it.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable operating system for servers and cloud environments. It also gives administrators the ability to manage and monitor resources through commands in the terminal. In this laboratory, I used Linux commands to check the operating system, kernel, CPU, RAM, disk capacity, mounted file systems, hostname, and IP address.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a record of the environment before changes are made. It allows engineers to understand the available resources and plan the infrastructure properly. It can also make troubleshooting easier because there is a reference that can be checked when problems occur.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using basic terminal commands and how to understand the information returned by those commands. I also practiced writing Markdown documentation, organizing files in GitHub, comparing cloud services, and creating a simple cloud infrastructure diagram.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized because I added a complete laboratory folder containing technical reports, documentation, screenshots, and a cloud architecture diagram. This activity also helped me practice presenting my work in a more professional and structured way. I can use the same approach for future cloud computing activities and projects.
